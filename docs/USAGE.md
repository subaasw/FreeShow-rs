# Using FreeShow-rs

How to run the app, what it reads from a FreeShow library, and how each integration is configured. For build and packaging see [PACKAGING.md](PACKAGING.md); for feature status see [PARITY.md](PARITY.md).

## Running

Install Rust 1.97 or newer and GStreamer 1.x (macOS: `brew install gstreamer libnice-gstreamer`). On Apple Silicon, point pkg-config at Homebrew before building: `export PKG_CONFIG_PATH="$(brew --prefix)/lib/pkgconfig"`. Video and cameras use GStreamer. Camera selection opens the device returned by native discovery rather than guessing its device index. Compressed camera feeds use a software decoder to produce CPU-readable frames. A disconnected camera reports an error; raw and JPEG camera feeds share the video decoder. Physical-camera testing remains pending. Audio uses the system output device. Then from this directory:

```sh
cargo run -p freeshow
```

Point it at an existing FreeShow library, or open one show:

```sh
cargo run -p freeshow -- --data ~/Documents/FreeShow
cargo run -p freeshow -- --show ~/Documents/FreeShow/Shows/Some\ Song.show
```

`scripts/present-sample.sh` builds a one-song library and opens the first slide on the output window.

## Running a service

Open a show from the drawer or the project list. Its slides appear as thumbnails and stay in view while you browse media, audio or other drawer tabs. Clicking a slide puts it on the output, as in FreeShow; the arrow keys, Page Up/Down (presentation clickers) and Space step through it, from the operator, output or stage window. The live slide carries a LIVE tag and the panel beside the slides shows the real output picture. Under it, **Clear all** (or Esc) blanks everything, and **Slide**, **Background**, **Overlays** and **Audio** clear one layer each.

**Edit** switches the show to editing (the button reads **Done** while editing): clicking a slide then only selects it, the preview shows the slide being edited, and **Go** puts it on the output. While presenting, **Prev** / **Next** step slides; **Duplicate** / **Delete** only show in edit mode. **Undo** / **Redo** sit in the edit header. **New show** opens straight into editing, and **Show text** edits the whole song as plain text. Stage notes for the selected slide edit beside the group name. Inspector and stage style fields save when you leave the box or press Enter. Click a colour swatch to open RGBA sliders and presets (or type hex beside it). The same picker is on theme colours, style backgrounds, and stage item colours. Inspector sections collapse (Box / Outline / Filters / Layout start closed) so Text and Position stay on screen while presenting. Settings → General sets the default slide and media transitions. The header screen menu lists connected displays by name (**Auto** keeps the previous second-monitor default).

Click **Displays** before presenting to check the connected screen count and the locations reported for the Audience and Stage windows. Use the screen picker to assign the audience, then click **Output** to open it. If the display in use disconnects, FreeShow closes the local audience window while the current cue and network output continue. After reconnecting, click **Output** to reopen it. To switch to another display, pick the connected screen explicitly. A saved stage location that is off screen falls back to the operator display.

Edits to the slide on air appear in the editor first. Select that same slide and click **Update Live** to publish the saved visual changes and stage notes without restarting its audio, video, or timer. **Go** takes the selected cue through its normal playback path. **Undo** and **Redo** reopen the show they affect, even after you browse to another show. If a write fails, the status bar reports the error and the same undo or redo remains available to retry.

FreeShow records a recovery draft before saving a show edit in the library. If a save fails or the app closes during the write, use the recovery bar to **Retry save**, **Save as copy**, or **Discard**. If the original show changed on disk, **Save as copy** keeps both versions and opens the recovered copy in the editor. **Discard** reloads the saved version when it is available. If the recovery folder itself is unwritable, the bar says **Draft in memory**. Save it before closing the app. Text still being typed before the save begins and a drag that has yet to finish are outside this recovery window.

To place a picture on a slide, choose a still image from the Media library picker in **Edit** and click **Add picture**. The new box opens in the inspector, where you can change its position, size, fit, crop, or flips. To swap an image, select one unlocked picture layer, choose another still, and click **Replace picture**. The swap keeps the layer’s geometry, effects, and crop. Use **Undo** to restore the previous source. Keep the source files in place so the slides can display them.

In **Edit**, click a box on the canvas to select it and drag to move it. Drag the square handle to resize a single visible, unlocked layer. The handle follows the layer’s rotation and the opposite corner stays in place. Hold **Shift** when you start the resize to keep the layer’s proportions. An empty slide asks you to **Add box** or **Add picture** first, the inspector explains the same when nothing is selected, and the stage editor points to **Add item** for an empty layout.

Above the canvas, use **+** and **−** to zoom between 100% and 400% of the fitted slide. At higher zoom, turn on **Pan** and drag the canvas or use the arrow keys while it has focus. Turn off **Pan** to resume editing. **Fit** centers the whole slide and restores the default zoom. These controls affect the editor view only.

The **Layers** list shows boxes from front to back. Click a layer or use arrow keys while the list has focus to select it. Turn on **Add to selection** to collect a set from the list. You can also hold **Command** on macOS or **Ctrl** on Windows and Linux while clicking boxes on the canvas to add them. Use **Exclude current layer** to remove the active box from the selection, or use **Keep current only** to return to one layer. The inspector controls the active layer.

Drag a selected box to move the selection together. **Duplicate**, **Remove**, and the stacking buttons also work on the selection. **Align to slide** aligns one layer to the canvas. For a selection, **Align selection** uses its enclosing box, and **Distribute** makes the gaps even between three or more layers. Box numbers follow the saved order, including when a stage layout displays a specific box number.

Select related layers and click **Group layers** to save them as a group. Selecting a group member normally selects the whole group. Drag or nudge it to move the members together, use **Align group to slide** to keep their spacing, or duplicate it as a separate group. Use **Keep current only** to edit one member or **Select group** to select them together again. **Ungroup layers** removes the grouping and keeps the layers in place. Saved groups also carry over when a slide is used as a template.

To resize a saved group, drag the square handle on its outer outline. The opposite corner stays fixed as the layer boxes and text sizes scale proportionally. A locked member disables the group handle. Hidden members still scale with the group, and the handle appears when at least one member is visible. One **Undo** restores the layout. Use **Update Live** to apply the edited slide to the audience while it is on air.

When you edit text in a layer, unchanged text around the edit keeps its existing fonts, colors, and other formatting. Highlight words in the slide text field, then use **Selected text** to make them **Bold** or **Regular**. To resize or recolor the selection, enter a size from 12 to 400 px or a hex color such as `#ffee00` and press Enter. Check the result on the Edit canvas and use **Undo** to reverse the format. The Inspector’s typography controls apply to the whole text layer.

Use **Lock** to protect the selected layers from text, style, geometry, stacking, and removal edits in the native editor. **Unlock** restores editing. **Hide** keeps the layer and its contents in the list so you can choose **Show** later. Hidden layers are omitted from preview, audience, stage, and remote output. Once a slide is on air, use **Update Live** or take it again to publish the visibility change.

With **Snap** on, move a selection near an edge or center line of the slide or another layer to see an alignment guide. A drag saves once when you release it. **Escape** cancels a drag. With the canvas focused, arrow keys nudge the selection by one source pixel and **Shift** increases the step to ten. Numeric position and size fields remain available in the inspector. Use **Tab** and **Shift+Tab** to move focus, and **Enter** or **Space** to activate a focused button.

In **Edit → Transition**, choose the effect, duration, and easing for the selected slide. Direction is available for Slide, Push, Wipe, Cover, and Uncover. **Inherited** follows the active output style or the library default. The inspector shows which one supplies the current effect. Changing a control creates a slide override.

To animate one layer, select it and open **Layer Animation** in the inspector. Choose an entrance such as **Fade**, **From left**, or **Scale in**. **Scale in** grows the layer around its center, and **Scale out** shrinks it on exit. Assign several layers the same step to play them together. Step 0 plays on Take. For later steps, set **Start** to **On Click** for a press of **Next** or **After Previous** to wait for every entrance on the prior step. If the first step uses **After Previous**, it starts on Take. The optional exit's delay starts when its own entrance finishes.

**Previous** rewinds the last step started by a click, including any automatic steps that followed it. A timed advance waits for the scheduled automatic entrances to finish. Press **Next** to advance manually.

**Build order** lists the animated layers in playback order, with the start trigger beside each layer. Select a row to edit that layer. Set its **Step** to move it earlier, move it later, or join another step.

Click **Preview animations** to rehearse the selected slide off air. The preview starts at Take. Use **Next** and **Previous**, or the arrow keys, to step through the builds. **Restart** resets the sequence. The preview uses the saved layer layout and local still images, including the slide's background. Close it with **Escape** or **Close**.

**Previous** rewinds the most recent manual step once any later text reveals have been rewound. Going back to an earlier slide shows its completed builds. Taking a slide directly starts its animation again. **Clear Slide** and **Clear All** cancel the slide's animations. Automatic advancement waits for pending manual steps. A timed destination that became due while waiting advances once the last manual step has been triggered. Layers already using click or line reveal keep those controls.

Click **Preview transition** to play the effect in a separate window. It uses stills from the previous enabled slide and the selected slide, starting on black if there is no previous slide. Use **Replay** or drag the progress slider to revisit a moment. Press **Escape** to close the preview. The preview leaves the audience, stage, remote controls, and audio on the current cue.

Use **Apply to range…** to copy the selected slide’s transition to an inclusive range in the current layout. The first slide is number 1. Select **Inherited** and use **Reset range** to remove the range’s overrides. **Undo** reverses the whole range edit in one step.

During a live transition, **Go** starts the next slide from the latest picture sent to the output. **Clear all**, **Slide**, and **Background** take effect immediately and discard queued pictures from before the clear.

In the slide inspector, **Radius** accepts pixels or percentages. Enter up to four values per axis in top-left, top-right, bottom-right, bottom-left order. Use `/` between the horizontal and vertical values to make elliptical corners, as in `40% 0 0 / 20px 0 0`.

### Templates

Open **Templates** and select a card to preview its design. Search filters the cards by name. **Use as New** creates an editable show with a copy of the template’s text, layers, background, and slide size. The new show opens in Edit and is added to the selected project if one is open. Its changes stay with the new show.

Cards marked **Starter** come with FreeShow. Start with lyrics, scripture, an announcement, a welcome title, or a service countdown. Use **Use as New**, then select each text box and replace its sample text in Edit.

For **Service Start — Countdown**, select the digits in Edit and enter the duration as `MM:SS` or `HH:MM:SS`. The countdown starts when you take the slide, updates once a second, and holds at zero until you advance or clear it. Taking the slide again restarts it. **Update Live** keeps the elapsed time when you change the duration. Previews show the authored duration.

Select a card and choose **Add to favorites** to mark it with a star. **Favorites only** works with Search. Favorite marks are saved in the current library and stay local when you share a template.

**Apply Style** uses the first template text box to restyle the unlocked text boxes in the open show while keeping their words. It applies across the show and can be reversed with one **Undo**.

To reuse a slide, pick it in **Edit**, choose **Save as template**, enter a name, and save. Its layers and design appear in Templates. Picture layers keep their original media references in the library.

### Download, preview, and relink media

In **Media**, turn on **Preview muted** and choose a picture or local video. It opens in a separate preview window. Videos can be paused or replayed, and the audience and audio outputs stay on the current cue.

Choose **Download video** and paste an authorized direct link to an MP4, MOV, WebM, or MKV file up to 2 GiB. Add an optional name and choose **Save video**. FreeShow shows progress and checks that it can decode a video frame from the local copy before adding it to **Media**. Choose **Cancel download** to discard an incomplete transfer. After a failure, correct the link if needed and choose **Save video** again. The completed video works offline and can be previewed or cued like other local media. Its local source credit contains only the link’s origin.

If FreeShow closes during a download, reopen it or start the download again to discard the incomplete copy. If the library disk is full, free up space before retrying.

Use **Find missing media** to check the open show and current project. Select the missing reference, then drop one replacement file or paste its path and click **Relink**. FreeShow copies the replacement into the library and preserves the cue’s settings. A show relink can be undone in one step. Take the cue again when you want the audience to see the replacement.

### Share a project or template

Use **Functions → Export package** for the open project, or select a card in **Templates** and choose **Export template**. Both write a `.project` archive under the library’s `Exports/` folder. The project package includes the selected shows, their stage notes, referenced designs, and supported local media that FreeShow can find. The template package contains the editable design and its media, with private notes removed. The status bar reports missing, external, or protected media and names fonts to check on the receiving computer.

On the receiving computer, drop the archive onto the operator window or place it in the library’s `Imports/` folder. Projects appear in the project list, and shared templates appear in **Templates**. If a received ID or media name conflicts with existing material, import keeps the existing copy and updates the incoming references. Identical media in the archive shares one file. Imports publish the project after its files and design entries are saved.

Font names and text formatting stay editable. If the import names a font you do not have, install that font on the receiving computer and reopen FreeShow, or choose an available font in the slide inspector. For a drop import, the status bar shows the first dependency warning and the full list is in the log.

Archives use FreeShow’s documented `data.json` and `files` layout for project media. Template-only archives use an additional field for the Rust app’s template gallery. The limit is 768 MiB unpacked, including at most 16 MiB of project metadata.

Drop songs, pictures, video, audio, or Bibles onto the operator window to import them into the open library. When a file cannot be copied, the status bar reports the failure and the rest of the batch continues.

Audience slides and the native stage window render saved FreeShow QR boxes with their configured payload and colors. The code stays square in a rectangular box. A Current Output box previews the active audience picture on the native stage and its browser view, with the saved output name when requested. Stage text boxes honor saved text-box numbers, item order, and stage bindings for multilingual slides.

Put song sources in the library `Imports/` folder before opening the library. ProPresenter 4–6 XML (`.pro4`, `.pro5`, `.pro6`) and `.proBundle` archives import lyrics, group children, disabled slides, notes, and slide backgrounds. Bundled media is copied into `Media/` and the saved shows point there; existing files are kept, and matching media is reused on repeat imports. Missing or ambiguous bundle media produces an import warning instead of linking to another file. ProPresenter 7 `.pro` files and bundles retain cue groups, the selected arrangement, slide notes, backgrounds, and separate text boxes with saved bounds and box-level typography. Mixed RTF runs preserve fonts, sizes, colors, bold, italic, underline, strikethrough, paragraph alignment, all caps, and letter spacing within the box. Raised and lowered RTF runs keep their offsets. Superscripts and subscripts use scaled glyphs. Legacy RTF hex escapes use the declared document code page or font charset. Imported lyrics and notes preserve typographic punctuation and spacing and omit hidden RTF text. Audience output draws imported text highlights and character background colors behind their runs. Text boxes retain saved margins, glyph outlines, and text drop shadows. Rectangles, ellipses, triangles, rhombuses, regular polygons, and stars retain their placement and layer order, with solid, linear, or centered radial fills. The Rust compositor applies stored rotation to ordinary slide items. Background Blur and Color Invert fills follow the shape outline and use the native backdrop filters on the picture underneath. Timed cues can advance within the selected arrangement, return to its first eligible slide, or jump to the first eligible occurrence of a specified cue. The timer also runs during background playback. Immediate global clear-audio and clear-background cues use the native slide actions. Standalone audio and background clears keep the last slide on the audience and stage. Delayed media and global clear actions count from the slide trigger. They continue while browsing and are canceled when another slide goes live. Imported timeline slides, background pictures and videos, and global Clear Slide, Clear Audio, Clear Background, and Clear All actions play at their recorded times in the selected arrangement. Background media cues keep the current slide visible. Foreground pictures and videos cover the current slide and clear when another slide is triggered. Imported foreground videos are audible by default. Imported videos can hold the last frame, stop on black or clear, or fade to black or clear. Fades use the native media transition duration. Imported video cues also retain their in and out points and playback speed. Imported timeline soundtracks play through the native audio output and restart when the timeline loops. Imported audio cues can start a file on a slide or at a recorded timeline time and honor its loop and retrigger settings. Audio cues and soundtracks share the native audio player and retain their saved in and out points and playback speed. Timelines marked to loop repeat at their saved duration. Without a saved duration, they loop after the last cue and soundtrack playback. Other tracks and unsupported graphics and cue actions remain incomplete. Bundles are limited to 10,000 entries, 16 MiB per presentation, 512 MiB per media file, and 2 GiB uncompressed in total. MediaShout XML/SSC and JSON table dumps, Quelea XML/`qsp`, SoftProjector `.sps`, EasySlides, VerseView, VideoPsalm, CSV, image-only shows, and FreeShow project packages (JSON or zip) also import from `Imports/`. PDF pages render through Poppler's `pdftoppm` at about 1920 px wide; without Poppler the import reports it instead of adding a placeholder. Legacy `.ppt`, Keynote `.key`, and OpenDocument `.odp` decks are rejected with a save-as-`.pptx` or PDF message. Native MediaShout `.mdb` and Canva presentations are not imported.

PowerPoint `.pptx` imports keep the presentation's saved slide order and hidden slides. Title and body placeholders without their own size inherit geometry from the slide layout or master, so text is not stuck in a 1x1 box. Speaker notes are imported as plain text for stage layouts with a Notes item. Saved automatic advance timings use FreeShow slide timers when the deck enables timings. Named custom shows and saved slide ranges become FreeShow arrangements. PowerPoint section names appear as slide groups in each arrangement. FreeShow opens the saved selection and keeps the full deck available as an arrangement. A timed final slide restarts the selected arrangement when the deck enables looping. Cuts, fades, fades through black, pushes, wipes, covers, and uncovers use the saved visual duration when available. Cover and uncover preserve corner directions. Legacy speed presets are approximate, and other effects use the FreeShow transition settings. PNG and JPEG backgrounds can be inherited from a layout or master. Embedded images are copied into `Media/` with their stretch and crop. Linked image backgrounds keep their URL, and tiled backgrounds repeat across the slide. Theme fills use the deck’s style matrix and the active slide color map. Backgrounds preserve tint, shade, luminance, opacity, and gamma adjustments, along with linear and circular gradients. Linear gradients preserve fractional angles and PowerPoint’s aspect-ratio scaling. The Rust compositor preserves radial point and elliptical focuses and rectangular focuses inside the slide for direct and theme fills. Shape paths on slide backgrounds follow the slide rectangle. Unspecified focus edges use the Office center defaults. Fractional gradient stops retain narrow color bands. Explicit empty stop lists fill black, and a one-stop fill uses its solid color. Eligible two-stop and three-stop gradients use PowerPoint’s per-channel gamma. Gradient tile rectangles preserve signed edge offsets and repeat with mirrored neighbors. Unusual tiled path gradients may differ from PowerPoint. Positioned shapes and text boxes keep direct and theme gradient fills. Ellipse shape paths follow the ellipse, and rectangle shape paths follow the box. Custom outlines support straight edges, quadratic and cubic Bézier segments, and elliptical arcs. Filled subpaths close even when the deck omits the close command. Outline points within the supported range can extend beyond the shape bounds and are clipped to the item box when painted. Points and arc parameters can reference DrawingML guide formulas. A path without its own coordinate dimensions uses the shape’s saved dimensions for those axes. Multiple filled paths keep their paint order and lightening or darkening modifiers, and oppositely wound contours in one path create cutouts. Triangles, right triangles, diamonds, and the 4- to 32-point star presets retain their outlines and saved numeric adjustments. So do block arrows, chevrons, pentagonal arrows, parallelograms, trapezoids, hexagons, octagons, plus shapes, and rectangles with rounded or snipped corners. Their adjustments use the shorter side of the original shape, so a wide arrow keeps the right head proportion. Pie, wedge, chord, and arc fills preserve their curved outlines. Donut and prohibition symbol fills retain their cutouts and saved thickness. Block arcs keep their sweep and band thickness. Cube, bevel, folded corner, and cylinder fills preserve their separate shaded faces. The visible fill is clipped to the item box when a preset extends beyond it. Point-focus shape-path gradients reach the actual edges of convex outlines and concave outlines whose full boundary is visible from the focus. Straight connectors and line shapes keep their position, direction, and solid stroke color and width, including values inherited from a theme. Preset and custom dash patterns are preserved, along with flat, round, or square end caps. Custom dash and gap lengths follow the saved percentages of the stroke width. Round caps count toward dash length. Square caps count toward preset dash length and extend custom dashes. Reimport a deck to apply these cap rules to connector patterns imported by older builds. Straight lines support triangle, stealth, open-arrow, diamond, and oval end markers with saved width and length settings. Double and triple strokes keep their separate bands and thick/thin order. The band-width proportions are approximated. Elbow connectors follow their saved bends with miter joins, continuous dash patterns, and end markers oriented along the adjoining segments. Positioned objects keep their rotation. Pictures keep both flips and their source crop. Shape flips also reflect gradient fills. Fills with Rotate with shape disabled keep their orientation in slide coordinates. Nested groups keep their transformed positions, scales, rotations, flips, and stacking order. Their children import as individual items. Positioned text keeps mixed font sizes, Latin theme fonts, run colors, highlights, bold, italic, underline, strikethrough, and letter spacing. Mixed sizes share a baseline. Saved character offsets raise or lower individual runs, with space reserved above and below the baseline. Wrapping keeps words together across formatting changes. Unicode break points allow ordinary breaks in Chinese and Japanese, honor nonbreaking spaces, and keep combining marks with their base characters when an oversized word must split. Paragraph alignment, vertical anchoring, explicit line breaks, text-box insets, line and paragraph spacing, and paragraph margins and indents also import. PowerPoint text boxes with wrapping disabled keep their explicit line breaks. Text remains clipped to the shape bounds. Saved normal autofit imports the font scale and percentage line-spacing reduction. FreeShow keeps these values when text is edited. Character bullets and automatic numbering preserve inherited font, size, and color. Decimal, Latin alphabetic, and Roman schemes retain start values and nested list counters. Other numbering schemes use decimal markers. Picture bullets, complex text transforms, and extended gradient geometry remain incomplete.

Embedded PowerPoint transition sounds are copied into `Media/` and play when their slide opens. Looping sounds repeat until another audio cue takes over or a stop cue is reached. PowerPoint stop cues affect transition audio only. A transition sound uses the shared cue audio player and can replace audio already playing there.

**Settings → Connection** shows the running addresses for the phone remote and Stage web view, whether they require a password, and any listener startup failure. Open the listed network address on a device on the same network. An address starting with `http://localhost` works from the FreeShow computer. If prompted, click **Enter password**. The phone remote disables show controls when locked or disconnected and reloads the current cue after reconnecting. If a command's result is unknown, check the live cue before trying it again.

The Stage web view defaults to `http://<this-computer>:5511/` and the phone remote defaults to port 5510. It shows the native stage layout, including its clocks, timers, notes, still images, and QR codes. The ports come from the library `settings.json` when it sets `ports.remote` and `ports.stage`. Native stage layouts honor next-slide boxes and clock dates saved in older FreeShow libraries. Local stage video boxes loop silently. A slide-text box with `includeMedia` mirrors the current audience background or shows the still background of its offset slide. The stage editor lets you turn this on, choose a text box by number, and reverse box order when showing all boxes. The stage port serves layouts and current output and ignores show-control commands. Both speak FreeShow's message shape, `{ "channel", "data" }`, on a WebSocket at `/ws` and on the Socket.IO events `REMOTE` (remote port) and `STAGE` (stage port). When the library `settings.json` has `serverData.remote.password`, both pages require it and every socket connection must send `ACCESS` with that password before any channel is answered. The password is sent as the `x-freeshow-password` header on the page's HTTP requests. Channels that move the show are `API:next_slide`, `API:previous_slide`, `API:index_select_slide`, `API:clear_all`, `API:clear_slide`, `API:clear_background`, `API:clear_overlays`, `API:clear_audio`, `SHOW`, and `API:start_scripture`. `GET_SCRIPTURE` and `SEARCH_SCRIPTURE` read the Bibles in the library. `API:scripture_next` moves to the next verse. On connect the remote also receives `PROJECTS`, `FOLDERS`, and `PROJECT`. `SEARCH_SHOWS` finds a song, and `API:set_plain_text` saves lyric slides separated by a blank line. `API:create_project`, `API:rename_project`, `API:delete_project`, and `API:remove_project_item` edit the service list. `API:get_groups` lists verse and chorus groups. `API:change_layout` switches a song to another layout. `GET_TEMPLATES` and `API:set_template` list templates and apply one to the open song. `API:id_start_timer`, `API:id_pause_timer`, and `API:id_stop_timer` run a countdown from the library. `API:id_select_overlay` draws an overlay on the audience. `API:play_media` plays a file from the library, `API:pause_audio` holds it, `API:audio_seekto` and `API:video_seekto` move the playhead, `API:toggle_media_loop` turns background looping on or off, and the volume slider on the phone page sets the main output level.

Use the Layout menu in the stage editor to switch between saved layouts. New layout starts with an empty stage. Duplicate layout opens a separate copy of the selected layout, including hidden boxes. Set its name and background color, then press Enter in each field to save. The preview and stage frame use the first configured stage output’s resolution when it has saved bounds. Without those bounds, they use the audience resolution. Click a box in the preview to select it. Where boxes overlap, the front box is selected. Hidden boxes can be selected in the list. Select a box and drag its outline in the preview to move it. Drag the lower-right handle to resize the box. Position and size changes save when you release the pointer. Use Move backward or Move forward to change which box appears on top when they overlap. Turn off Show on stage to hide a box and use the same switch to restore it. Hidden boxes stay in the editor and in the saved stacking order. Set a box label to identify it in the list, and clear the label to restore its default name. For slide text or notes, a slide offset of 0 follows the current slide, 1 follows the next slide, and −1 follows the previous slide. The selection is restored when you reopen the library. The stage editor saves changes to the layout shown in its preview, including after a slide action switches layouts. In the stage editor, add a QR code box and enter the content and colors. Clear the background field to make it transparent. An output picture box previews the active audience output. Choose a named output to show the picture only while that output is active, and turn on Show output name to label it. Add a camera box to select a connected camera, choose how it fits the box, and flip it horizontally or vertically. Reopen the stage editor to refresh the camera list. Add a chart box and choose Bar, Line, or Pie. Enter one `Label: value` per line or paste FreeShow JSON chart rows, then select Apply chart data. For a doughnut chart, choose Pie and set the hole size above zero. Add a Web preview box for a static page-address card. An optional local still image takes precedence over the card. Clear the still image field to return to the card. For media and web still boxes, pick a file from the Media library list and click **Use**, or type a path and press Enter.

Audio files and video sound follow the library's `audioRouting.connections` graph through `audioChannelsData` mixer gains to the default speaker or named speaker devices. Slide audio and drawer audio use `drawer_audio`; playlists use both `playlist_sub_<id>` and `playlists_default`. A source with no speaker connection stays silent. The phone page lists mixer channels and lets you set each channel's volume and mute independently. Main affects paths through the Main channel. Video sound uses `output_window` and `output_win_sub_<audience-output-id>` and keeps the clip's stored volume.

Use **Settings → Audio routing → Scan output devices** to check audio files, audience video, and playlist routes. The report shows the current mapping, mixer level, and configured network destinations. Audio-file checks include the output channel count reported by the device. For video, rehearse with a clip to verify the actual ports. Click **Scan output devices** again after changing your hardware.

Use **Device mappings** to match a named library speaker to a native device on this computer. Restart FreeShow to apply the saved mapping. Current playback keeps its running mapping. You can also list audio-file devices with `--list-audio-devices` and video speaker devices with `--list-video-audio-devices`, then edit this app's `settings.json` directly, for example:

```json
{"audio_devices": {"speaker_sub_<FreeShow-device-id>": "Stage Speakers"}}
```

Keep the other app settings when adding that field. An unavailable mapped device logs an error and does not fall back to the room speakers. Audio-file speaker devices and network feeds use independent playback clocks. Video sound uses GStreamer speaker sinks on its playback clock. Hardware speaker connections honor `channelIndex`/`toChannelIndex` and an explicit `fromChannelIndex`. A single selected speaker port receives a mono mix; multiple selected ports preserve the corresponding source channels. Named speaker connections without an index use port 0, as FreeShow does. Audio and video share the same channel matrix, and unmapped ports stay silent. Changes to video channel routes and their mixer gains take effect during playback. Active video audio branches apply the latest queued route on the streaming thread when the next buffer arrives. Indices are zero-based and must be below 64; unavailable device channels fail without falling back to the room speakers. Stereo network feeds follow `network_sub_<output-id>` routes and keep audio-file and video sources separate until the sender mixes them. A network-only audio file needs no physical output device. The PCM effects chain supports gain, peaking EQ, delay, compressor, and limiter.

In **Settings → Icecast**, enter the host, port, mount, and source password, then choose **Save connection**. Leave the password field blank to keep the current password. Saving updates the destination as a single change. Choose **TLS** for a certificate-verified Rust connection, **HTTP** for plain HTTP, or **Automatic** for existing negotiation. TLS checks the host against the server certificate and uses FreeShow’s bundled public trust roots. Automatic uses `shout2send` where available and Rust HTTP otherwise. The choices are stored in `special.icecast` in the library’s `settings.json`.

To route audio from the native app, select **Use Main mix when no Icecast route is saved** and save the connection. A saved Icecast route takes precedence. The Main mix option uses the default mix in a library without a routing graph and follows the Main channel in a library with a graph. Saving a new route includes audio and video that are already playing. Icecast sends stereo Ogg Opus and starts disabled when the Main mix route is first configured. **Functions → Enable/Disable Icecast**, slide actions, and the password-gated `API:toggle_icecast` command control when the routed stream is enabled.

Icecast 2.4.4 can leave a mount active after a clean TLS disconnect.

OSC input listens on UDP port 5505, the same port FreeShow uses. `/freeshow/slide/next`, `/freeshow/slide/previous`, `/freeshow/slide/1`, `/freeshow/clear/all`, and `/freeshow/show/<id>/start` drive the open show.

MIDI input opens the first connected input, or the port named by `FREESHOW_MIDI_IN`. FreeShow's default notes are used: channel 1 note 0 is next, note 1 is previous, channel 3 note 0 clears, and channel 5 note 2 selects a slide from the velocity.

Each enabled, ungrouped NDI output in the library sends its picture and routed stereo audio through the GStreamer NDI plugin. Audience outputs send the audience picture; stage outputs send the stage picture. A source name uses `ndiData.name`, or `FreeShow NDI - <output name>`. With no enabled NDI output, nothing is broadcast. The plugin and NDI SDK runtime are required. Grouped outputs stay disabled because the current sink does not expose NDI discovery groups. Each enabled OMT output advertises its audience or stage picture over the local network and sends its routed stereo mix. It uses `omtData.name`, or `FreeShow OMT - <output name>`. OMT sending is built into FreeShow. Enabled WebRTC outputs encode H.264 and stereo Opus through webrtcbin. Each WHIP stream uses the saved mix routed to `network_sub_<output-id>` and publishes to `webrtcData.url` with an optional Bearer token.

Open **Settings → Network outputs** to check NDI, OMT, WHIP, RTMP, and Icecast before a service. The tab shows sender startup, unavailable pipelines, and the selected Audience or Stage picture. WHIP negotiation runs in the background. RTMP uses one sender, and the report identifies which automatic destination was selected. Verify picture and sound on the intended receiver. Icecast shows whether streaming is enabled in the mixer.

To start with a network video background, set `FREESHOW_OMT_IN` to a discovered name such as `BOOTH (Lobby)` or a direct URL such as `omt://192.168.1.20:6400`. You can also set `special.omtInput` in the library’s `settings.json`. For a GStreamer NDI source, use `FREESHOW_NDI_IN` or `special.ndiInput`. During a service, open **Media** and click **Find network sources**. Choose an NDI or OMT feed and click **Use source**, or enter a direct OMT address and click **Use OMT address**. The feed plays behind slides until you clear or replace the background. Use the picker again to restart it.

MIDI timecode uses the first input, or the port named by `FREESHOW_MTC_IN`. Quarter-frames and full frames replace the stage clock with `HH:MM:SS:FF` while they are arriving. Linear timecode listens only when `FREESHOW_LTC_IN` names an input (`default` uses the system input) and uses 25 fps unless `FREESHOW_LTC_FPS` is set.

Functions → Record writes the audience picture to `Recordings/freeshow-YYYYMMDD-HHMMSS.mp4` in the library. Choosing it again, or closing the app, closes the file. Local MP4 recording is still video only. `FREESHOW_RTMP` streams the current picture with routed stereo AAC audio to that URL. It uses the first enabled RTMP output ID in the library, or `default` when none is configured; route to `network_sub_<id>` to feed it. Saved `rtmpData.destinations` can start through their auto-start flags or `special.autoRtmp`. The app supports one active RTMP destination. Static pictures repeat at 30 fps so media audio can continue without slide changes. The RTMP pipeline corrects source timing gaps up to 250 ms. Network feeds require the GStreamer `inter` plugin; RTMP also requires an AAC encoder (`avenc_aac`).

Planning Center loads when `FREESHOW_PCO_TOKEN` is a Services access token and `FREESHOW_PCO_PLAN` is `serviceTypeId/planId`. `FREESHOW_PCO_FILE` can point at a saved plan document instead. Songs and plan items become shows, headers stay section labels in the project, and Functions → Planning Center loads the plan again. With neither a token nor a file, the app does not contact Planning Center.

ChurchApps loads the presenter plans for `FREESHOW_CHURCHAPPS_TOKEN`, or a saved plan from `FREESHOW_CHURCHAPPS_FILE`. Arrangement lyrics become shows, with later lyric blocks kept as child slides, and Functions → ChurchApps loads them again. Without a token, service-plan API requests are disabled.

Lessons.church `.olp`, `.olf`, and lesson `.json` files in `Imports/` are imported at startup or through Functions → ChurchApps, without an account. `FREESHOW_CHURCHAPPS_FILE` can also point at one lesson document. Cover images and media from playlist groups or OLF `play` actions download over HTTP/HTTPS into `Media/Lessons/`. The resulting shows are added to the `Lessons.church` project only after every media download finishes. Grouped slides keep video loop flags, audible video sound, and advancement after a non-looping video except on the final slide. Completed downloads are cached for offline reuse; repeated imports keep operator edits. Failed or truncated transfers do not publish a lesson and can be retried. Limits are 16 MiB per source file, 2,000 media slides, and 2 GiB per media file. Downloads run in the background at startup or after the Functions action. The footer shows downloaded bytes for the current file and offers Cancel import. Cancellation waits for any in-flight network read to return before cleaning up the partial file. Completed media stays cached. Service-plan publication keeps unrelated project edits and skips the refresh if an imported project changed during preparation. Service-plan lesson sections, actions, and add-ons also use this local media cache. Venue plans resolve their public feed, and a venue service with no custom order follows its playable feed actions. Uncached add-ons use the public add-on lookup. Service-plan media stays in service order, keeps its explicit loop flags, and stores scheduled durations. Failed metadata or media requests keep the previous service and show files. Saved service-plan documents must include the resolved `files` arrays on lesson children. Public lesson and media requests do not carry the service account token. Vimeo, YouTube, and other stream-only items are published with their remote URL as the media path and are not downloaded. Direct HTTP video files play through GStreamer. YouTube and Vimeo pages can play when `yt-dlp` is installed and resolves a playable stream.

Functions → Backup writes `Backups/YYYY-MM-DD_HH-MM.zip` with shows, portable config, and bibles in the FreeShow backup names. Functions → Restore puts the newest of those zips back into the library. `FREESHOW_CLOUD_DIR` also receives a copy, and `FREESHOW_CLOUD_URL` receives a PUT of the zip (`FREESHOW_CLOUD_TOKEN` is sent as a bearer token when it is set). A failed copy or upload keeps the local zip and the show continues. When neither destination is set, the app does not upload on startup. Functions → Export PDF, Export package, and Screenshot write a lyrics PDF (Latin-1 text; other scripts become `?`), a `.project` zip of the open project, and a PNG of the current audience frame under `Exports/`. Success and failure both show in the operator status bar. Functions → Metronome starts and stops a beat from the stored `metronome.tempo` (or `bpm`) and `beats`; the footer also shows a configured `timecode` mode. When `fullColors` is on, slide labels use the group color as a fill; otherwise a color bar marks the group. `slidesOptions.columns` and `mode` lay the slide list out as a grid, except `list` and `lyrics`, which stay one column. The show/media drawer sits along the bottom at `drawer.height` (default 300px) and is hidden in focus mode. A first-run guide appears until dismissed. Functions → Undo / Redo, Focus mode, Guide, Kiosk, Always on top, and Shortcuts match the default chords Ctrl+Z, Ctrl+Y, Ctrl+Shift+F, Ctrl+F1, F11, and Ctrl+Shift+A; Functions → Shortcuts edits those bindings. As in FreeShow, Esc or `.` clears everything, F1 clears the background, F2 the slide, F3 the overlays, F4 the audio, and F5 goes to the next slide.

OBS uses WebSocket 5. `FREESHOW_OBS` is `host:port` (port 4455 when the host has none) and `FREESHOW_OBS_PASSWORD` is the server password. When those are unset, the library `obsData` (`ip` or `host`, `port`, `password`) is used if it is enabled. Functions → OBS scene sends `SetCurrentProgramScene` for `FREESHOW_OBS_SCENE`. Functions → OBS stream and OBS record start and then stop that output. When `FREESHOW_OBS` and `FREESHOW_OBS_SCENE` are both set, the scene is selected at startup. A closed OBS is logged and the show continues.

Functions → AI rewrites the selected slide through Ollama when `FREESHOW_AI` is `ollama` or a base URL such as `http://127.0.0.1:11434`. `FREESHOW_AI_MODEL` defaults to `gemma3:4b`, and `FREESHOW_AI_PROMPT` is the instruction. The model replies with slide lines, which replace the selected slide. With `FREESHOW_AI` unset, the app does not contact a model.

Every 15 minutes the open shows and the project file are saved again. A file whose bytes did not change is left alone, so the `Backups` folder does not grow. Each save still writes a temporary file, flushes it, and renames it into place.

## Windows and configuration

The operator window is Slint. Audience and stage windows show frames rendered by the `freeshow-output` crate and uploaded with wgpu. Those frames are not drawn as Slint widgets.

Settings and the log are stored in the app config directory:

- macOS: `~/Library/Application Support/freeshow-rust/`
- Windows: `%APPDATA%\freeshow-rust\`
- Linux: `$XDG_CONFIG_HOME/freeshow-rust` or `~/.config/freeshow-rust`

`FREESHOW_CONFIG_DIR` overrides that path. `settings.json` holds the theme name (when set), the FreeShow library path, and whether the output and stage windows open on launch. When no theme is set here, the library's own FreeShow theme is used. Custom theme colors and fonts are read from `Config/themes.json` using the theme ID selected in the library settings. The library `settings.json` also supplies `outLocked`, `lockedOverlays`, `splitLines`, and the other keys listed in `PARITY.md`; locked overlays stay on when a library opens, and `outLocked` blocks output changes. `splitLines` splits imported and edited lyric pages, `customFonts` files are used when a slide names that family, and `resized` left/right panel widths size the operator lists. The header Search box filters the current drawer tab. Missing or malformed values keep the built-in defaults. Font family and `em` font size apply to the operator window; unavailable fonts use the system fallback. `RUST_LOG` controls stderr tracing (default `info`).
